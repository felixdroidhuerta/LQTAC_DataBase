# LQTAC dbFox 0.2.5

- Las conexiones y grupos se exportan con la extensión .foxdb. La importación conserva la compatibilidad con .lqtdb.
- Los dashboards se exportan con la extensión .foxpanel. La importación admite también .lqtac-dashboard y .json.
- El manual incluye los nuevos formatos.

Para actualizar el portable, extrae el ZIP en otra carpeta y copia tu carpeta Data con ambas aplicaciones cerradas. Las contraseñas guardadas pueden requerir volver a introducirse en otra cuenta o equipo.
