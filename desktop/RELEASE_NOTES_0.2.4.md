# LQTAC dbFox 0.2.4

- Nueva identidad dbFox by LQTAC, con icono del zorro y marca renovada.
- Crear bases SQLite locales vacías y abrirlas para trabajar con ellas.
- Copias de conexiones y grupos en archivos .lqtdb cifrados, incluidas las contraseñas guardadas.
- Edición directa de celdas compatibles con doble clic o F2, con cambios pendientes hasta aplicarlos.
- Ventana Acerca de, ayuda y manual ilustrado actualizado a dbFox.

Para actualizar el portable, extrae el ZIP en otra carpeta y copia tu carpeta Data con ambas aplicaciones cerradas. Las contraseñas guardadas pueden requerir volver a introducirse en otra cuenta o equipo. SQLite se trabaja en memoria: usa Guardar copia para conservar cambios.
