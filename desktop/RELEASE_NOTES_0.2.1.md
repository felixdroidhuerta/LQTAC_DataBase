# LQTAC Data Base 0.2.1

- Tarjetas de texto y tarjetas vinculadas a campos de consultas en los dashboards.
- Contraseñas opcionales guardadas cifradas mediante el sistema y conexión directa.
- Duplicación de conexiones con su contraseña guardada, si existe.
- Opciones para cambiar u olvidar contraseñas guardadas.

El portable incluye el manual de la versión 0.2.0; estas novedades aún no están documentadas en él. Para actualizar, extrae la nueva versión en otra carpeta y copia la carpeta Data con ambas aplicaciones cerradas. Las contraseñas cifradas pueden requerir volver a introducirse en otra cuenta o equipo.
