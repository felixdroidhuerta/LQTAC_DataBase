# LQTAC Data Base 0.2.2

- El icono de LQTAC se incorpora al ejecutable portable para que Windows pueda mostrarlo al anclar la aplicación.
- Incluye todas las mejoras de la versión 0.2.1.

Para actualizar, extrae el ZIP en otra carpeta y copia la carpeta Data con ambas aplicaciones cerradas. Desancla el acceso anterior y ancla el nuevo ejecutable. El manual incluido corresponde a la versión 0.2.0.
