# LQTAC dbFox 0.2.6

- Conexiones MySQL y MariaDB por TCP/IP, socket local o túnel SSH.
- Autenticación SSH por clave/agente o usuario y contraseña, con verificación de identidad del servidor.
- Selector de servidor por consulta y conservación de respuestas con ediciones pendientes.
- Paginación local y búsqueda sobre todas las filas cargadas.
- Buscar y reemplazar SQL en una cabecera organizada por secciones.
- Visualización de espacios, tabuladores y caracteres Unicode invisibles.
- Edición de contenido completo, revisión SQL antes de aplicar y confirmación del borrado múltiple.
- Valores NULL en columnas editables que los admiten.
- Identificación de registros por PRIMARY o UNIQUE NOT NULL en MySQL y MariaDB.
- Copiar y pegar definiciones de campos entre tablas.
- Manual 0.2.6 actualizado con capturas actuales. Ayuda y Acerca de abren esta edición.
- El ZIP de distribución excluye la carpeta personal Data.
